# ゴルフ オリンピック計算アプリ

iPhone 12のSafariで片手操作しやすいことを意識した、ゴルフのオリンピック用ポイント計算アプリです。HTML/CSS/JavaScriptだけで動作し、外部ライブラリは使用していません。

## ファイル構成

```text
.
├── index.html   # 画面構造
├── styles.css   # iPhone縦画面向けスタイル
├── app.js       # 入力・集計・localStorage保存処理
└── README.md
```

## 使い方

1. `index.html`をブラウザで開きます。
2. 初期表示では人数欄も名前欄も空白です。プレー人数を入力し、「名前欄を作成」を押します。
3. 空白で表示された各メンバー名を入力し、「ラウンド開始」を押します。
4. 現在ホールの各メンバーのポイントを入力します。
   - プラス、マイナス、0を入力できます。
   - 入力内容は自動的に`localStorage`へ保存されます。
5. 「前のホール」「次のホール」またはホール番号の選択で、1〜18Hを切り替えます。
6. 画面上部で現在ホール、入力済みホール数、総合トップを確認できます。
7. 画面下部の簡易ランキングで途中経過を確認できます。
8. 「詳細表示」を押すと、メンバーごとのポイント獲得ホール、合計、支払額（個人pt × 人数 - 全員pt）と、各ホールごとのメンバー別ポイント一覧を確認できます。
9. 「新規ラウンド開始」でメンバー設定画面へ戻れます。
10. 「データリセット」で保存データを削除できます。誤操作防止のため確認ダイアログが表示されます。

## GitHub Pagesでの公開方法

1. このリポジトリをGitHubへpushします。
2. GitHubのリポジトリ画面で **Settings** を開きます。
3. 左メニューの **Pages** を選択します。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選択します。
5. **Branch** で公開したいブランチ（例: `main`）と `/ (root)` を選択し、**Save** を押します。
6. 数十秒〜数分後に表示されるGitHub PagesのURLへアクセスします。

## iPhoneでの確認方法

1. iPhone 12のSafariでGitHub PagesのURLを開きます。
2. 縦画面のまま、人数入力、名前入力、ホール切り替え、ポイント入力を確認します。
3. Safariのタブを閉じて再度開き、入力済みデータが残っていることを確認します。
4. 「詳細表示」の開閉と「データリセット」の確認ダイアログを確認します。
5. 必要に応じてSafariの共有メニューから「ホーム画面に追加」して利用できます。

## ローカルでの動作確認

単純な静的ファイルなので、`index.html`を直接開いて利用できます。ローカルサーバーで確認する場合は、次のように起動します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開いてください。
